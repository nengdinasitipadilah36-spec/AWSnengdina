Fase 1: Pengenalan Konsep VPS & Cloud

Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia.

Shared Hosting

Layanan hosting di mana satu server fisik digunakan bersama-sama oleh banyak pengguna. Sumber daya (RAM, CPU, penyimpanan) dibagi rata sehingga biayanya paling murah dan mudah dikelola, tetapi performanya bisa terpengaruh jika ada pengguna lain yang trafiknya melonjak.

Dedicated Server

Layanan penyewaan satu server fisik secara utuh hanya untuk satu pengguna atau perusahaan saja. Seluruh sumber daya server (CPU, RAM, disk) digunakan secara eksklusif sehingga performa sangat maksimal dan kontrol penuh, namun biayanya jauh lebih mahal.

Amazon Lightsail

Layanan VPS dari AWS yang dirancang agar praktis, cepat, dan mudah digunakan dengan paket harga bulanan yang tetap (flat). Sudah dilengkapi komponen siap pakai (komputasi, penyimpanan, dan jaringan) sehingga sangat cocok untuk pemula, website sederhana, atau aplikasi skala kecil.

Amazon EC2

Layanan komputasi awan (IaaS) dari AWS yang menyediakan server virtual dengan fleksibilitas dan skalabilitas sangat tinggi. Pengguna bebas mengonfigurasi spesifikasi server secara mendetail serta menyesuaikan kapasitas secara otomatis sesuai kebutuhan trafik dengan sistem bayar sesuai pemakaian (pay-as-you-go).
